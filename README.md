A two-part micro-confession for Unsent: The Micro-Confession Sprint. The To: line names the nurse on the second night, and the message admits the buzzer was pressed twice for nothing, because the ward had gone quiet and falling asleep alone felt frightening. The addressee and the admission need each other: only the nurse who answered the buzzer could be told why it was pressed.

## Run it

```sh
python3 main.py
```

The program writes the two-part text to `/output/entry.txt` as UTF-8 text with no trailing newline, and checks the written file before it finishes.
